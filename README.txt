
Project: AI Research Paper Summarizer
Install: python -m pip install -r requirements.txt
Run: python -m streamlit run app.py
Enter your own Gemini key in the sidebar.
Select an available model and upload a text-based PDF.
Click Generate summary and verify the result.
Limits: 10 MB, 60 pages, 150,000 extracted characters.
No OCR. Internet and API access required.
Do not submit API keys or private papers.
